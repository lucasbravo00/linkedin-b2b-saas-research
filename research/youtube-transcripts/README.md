# YouTube transcripts

Transcripts organized by author, then by video, generated by
`scripts/fetch_youtube_transcripts.py`.

```
youtube-transcripts/
└── <author-slug>/
    └── <video-id>-<title>.md   # frontmatter (author, video URL, dates, word count) + transcript
```

Two real videos are seeded in `scripts/seeds/youtube_videos.csv` (Anthony Pierri).
Add more rows for the other experts — suggested channels/shows are listed in
`../../scripts/README.md`.
