# LinkedIn posts

One folder per expert (slug matches `research/sources.md`). Each author's `posts.md`
is generated by `scripts/collect_linkedin_posts.py` from a CSV of collected posts,
newest first, with source links and a one-line annotation per post.

```
linkedin-posts/
├── dave-gerhardt/
├── anthony-pierri/
├── finn-thormeier/
├── adam-robinson/
├── devin-reed/
├── amelia-sordell/
├── sara-stella-lattanzio/
├── richard-van-der-blom/
├── wes-kao/
└── emily-kramer/
```

Collection workflow (ToS-respecting manual/assisted) is in [`../../scripts/README.md`](../../scripts/README.md).
Target ~5–10 high-signal posts per author — signal over volume.
